## Core idea
Every tool you add is one more option the model must rule out. An agent with 18 tools picks less reliably than one with 4–5. Agents also misuse tools outside their speciality: a synthesis agent will start doing web searches. Give each agent only the tools its role needs, plus a narrow cross-role tool where a frequent need justifies it. Use `tool_choice` when you need a guarantee about *whether* or *which* tool gets called.

## What the exam tests
- Too many tools degrade selection. Scope each subagent's tool set (the `tools` list in its `AgentDefinition`) to its role.
- Replace generic, powerful tools with constrained ones. For example, replace `fetch_url` with a `load_document` tool that validates document URLs.
- For a high-frequency cross-role need, give a **scoped** tool (`verify_fact`) and keep routing complex cases through the coordinator.
- `tool_choice` options:
  - `"auto"`: the model may answer in text or call a tool.
  - `"any"`: the model must call *some* tool.
  - `{"type":"tool","name":"..."}`: the model must call *that* tool.
- Force a specific tool first (e.g. `extract_metadata`), then handle later steps in follow-up turns with `auto`.

## Exam traps
- **Trap:** give every agent every tool "for flexibility" → **Instead:** follow least privilege. Too many tools means more misrouting and cross-specialisation misuse.
- **Trap:** give the synthesis agent the full web-search toolset to cut round trips → **Instead:** give it a scoped `verify_fact` for the simple 85% of cases and send the rest through the coordinator.
- **Trap:** a prompt line "always call extract_metadata first" → **Instead:** forced `tool_choice` guarantees the first call.
- **Trap:** keep `tool_choice: "any"` on every turn of a multi-step flow → **Instead:** force only the step that must happen. Return to `auto` so the model can finish with text.

## Example
```python
# turn 1: guarantee the scaffold template is loaded before anything else
resp = client.messages.create(..., tools=tools,
        tool_choice={"type": "tool", "name": "load_project_template"})
# later turns: tool_choice={"type": "auto"} so the model can finish with text
```

## Remember
- About 4–5 role-specific tools per agent. Avoid 18 generic ones.
- Constrained tool > generic tool. Scoped cross-role tool > full toolset.
- `auto` = may call. `any` = must call one. `tool` = must call this one.
- Force the first step, then release.
- Docs note: the current API docs say some newest models (e.g. Opus 5.5, Sonnet 5.5) reject forced `any`/`tool` and recommend `auto` with strict tool use. For the exam, know the three options as listed in guide v1.0.
