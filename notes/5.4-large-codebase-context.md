## Core idea
Long exploration sessions degrade. As the context fills with file dumps and search output, the model starts giving inconsistent answers and falls back on "typical patterns" instead of the specific classes it found earlier. The architect's tools are to keep discovery out of the main context with subagents, persist findings outside the context (scratchpad files, state manifests), carry summaries between phases, and compact when needed.

## What the exam tests
- Signs of **context degradation**: inconsistent answers and generic references in place of specifics found earlier.
- **Scratchpad files** keep key findings across context boundaries, and the agent consults them for later questions.
- **Subagent delegation** isolates verbose exploration ("find all test files", "trace refund flow dependencies") while the main agent keeps coordinating.
- Summarise one phase's findings before spawning subagents for the next phase, and inject the summary into their initial context.
- **Crash recovery**: each agent exports state to a known location, and the coordinator loads a **manifest** on resume and injects it into prompts.
- `/compact` reduces context use when verbose discovery output has filled the session.

## Exam traps
- **Trap:** answers get vague late in the session, so re-ask more precisely → **Instead:** the context is degraded. Use the scratchpad, delegate or compact.
- **Trap:** the main agent greps and reads everything itself → **Instead:** delegate questions to subagents and keep only their summaries.
- **Trap:** on a crash, resume the transcript and hope it contains everything → **Instead:** use structured state exports plus a manifest of completed work.
- **Trap:** start phase 2 subagents with no context → **Instead:** inject the phase-1 summary.
- **Trap:** a bigger context window as the fix → **Instead:** attention degrades anyway. Manage what is in the context.

## Example
```text
.agent/scratchpad.md
- RefundService.issue() -> PaymentGateway.charge() (src/pay/gateway.ts:142)
- Legacy path: OrderV1Controller still calls refund directly (no audit log)
.agent/manifest.json
{"completed": ["map_modules", "trace_refund_flow"],
 "pending": ["find_tests"], "state": {"trace_refund_flow": ".agent/trace.json"}}
```
On restart the coordinator reads the manifest, skips completed work and passes `trace.json` into the next subagent's prompt.

## Remember
- "Typical patterns" talk is a sign of degradation.
- Scratchpad findings survive context limits.
- Subagents explore, the main agent coordinates.
- Use summaries between phases and manifests for crash recovery.
- `/compact` when discovery output piles up.
