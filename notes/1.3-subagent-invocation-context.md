## Core idea
In the Agent SDK a coordinator spawns subagents through the **Task tool**. Each subagent type is defined by an **`AgentDefinition`**: a description that says when to use it, a system prompt, and a restricted tool list. A subagent starts with a fresh context. The only thing it receives from the parent is the Task prompt, so everything it needs (findings, file paths, decisions) has to be written into that prompt.

## What the exam tests
- The Task tool spawns subagents, and the coordinator's `allowedTools` must include `"Task"`.
- Subagents do **not** inherit the parent's history or share memory between invocations. Pass context explicitly.
- `AgentDefinition` fields: `description`, `prompt` (system prompt), `tools` (restriction), and optionally `model`.
- Pass **complete** prior findings into the next subagent's prompt, for example search results and analysis outputs for synthesis.
- Use **structured** formats that separate content from metadata (URL, document name, page) so attribution survives.
- For **parallel** spawning, emit several Task calls in **one** coordinator response, not across separate turns.
- Coordinator prompts should state goals and quality criteria, not step-by-step procedures, so subagents can adapt.
- Fork-based sessions let you explore divergent approaches from a shared baseline (see 1.7).

## Exam traps
- **Trap:** the coordinator never delegates even though descriptions are good → **Instead:** check that `"Task"` is in `allowedTools`.
- **Trap:** "synthesize the findings so far" → **Instead:** the subagent has never seen them. Put them in the prompt.
- **Trap:** pass a short prose summary to save tokens → **Instead:** structured claim + source records. Prose loses attribution.
- **Trap:** independent subtasks spawned one per turn → **Instead:** issue all the Task calls in a single response.
- **Trap:** a micro-managing, step-by-step subagent prompt → **Instead:** give the goal, scope, output format and quality bar.

## Example
```python
options = ClaudeAgentOptions(
    allowed_tools=["Task"],   # exam term; current SDK docs name it "Agent"
    agents={"synthesis": AgentDefinition(
        description="Combines provided findings into a cited report section.",
        prompt="Use only the findings given. Keep every claim's source.",
        tools=["Read"])})
```
Task prompt to synthesis: the goal, then a JSON list of `{claim, source_url, doc, page, date}` items.

## Remember
- Task tool + `"Task"` in `allowedTools`.
- Only the Task prompt reaches the subagent: no parent history and no shared memory.
- Use structured content kept separate from metadata.
- Parallel means many Task calls in one response.
- Docs note: current Agent SDK docs call this the **Agent** tool (`tool_use` name `"Agent"`, still `"Task"` in the init tool list), and `allowedTools` is now documented as auto-approval.
