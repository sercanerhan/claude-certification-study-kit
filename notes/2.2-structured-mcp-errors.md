## Core idea
When an MCP tool fails, the agent can only recover sensibly if the result tells it **what kind** of failure happened. The MCP pattern is to return a normal tool result with `isError: true` and a structured payload, not a bare "Operation failed". The payload tells the agent whether to retry, fix its input, explain a policy to the user, or escalate.

## What the exam tests
- The `isError` flag marks a tool-execution failure in the tool result, so the model sees it and can react.
- There are four error categories: **transient** (timeout, service down), **validation** (bad input), **business** (policy violation) and **permission** (not allowed).
- Return structured metadata: `errorCategory`, `isRetryable` and a human-readable message. For business-rule violations, add `retriable: false` and a customer-friendly explanation.
- Uniform errors hide the cause. The agent then retries things that can never succeed, or gives up on things that would.
- An **access failure** is not the same as a **valid empty result**. "Query ran, 0 matches" is a success. "Could not reach the index" is an error.
- Subagents retry transient failures locally. They pass up to the coordinator only what they can't resolve, together with partial results and what they attempted.

## Exam traps
- **Trap:** catch the exception and return an empty list marked as success → **Instead:** that hides the failure. The agent will conclude that nothing exists.
- **Trap:** a generic "search unavailable" after silent retries → **Instead:** return the category, retryability, the attempted query and any partial results.
- **Trap:** retry every error with backoff → **Instead:** retry only `isRetryable: true` (transient) errors. Validation and business errors need a different action.
- **Trap:** throw so the whole workflow terminates → **Instead:** report the error as data so the coordinator can choose an alternative.

## Example
```json
{"isError": true,
 "content": [{"type": "text", "text": "{\"errorCategory\":\"transient\",\"isRetryable\":true,\"message\":\"Code index timed out after 30s\",\"attempted\":\"callers_of('chargeCard')\",\"partialResults\":[\"billing/api.ts:88\"]}"}]}
```
For "the index is healthy and nothing calls this function", return `isError: false` with an empty list.

## Remember
- `isError: true` plus category, retryable flag and readable message.
- Transient → retry. Validation → fix the input. Business → explain or escalate. Permission → don't retry.
- Empty result ≠ failure. Never encode one as the other.
- Recover locally first, then propagate with partial results.
- Spec note: MCP separates JSON-RPC *protocol* errors (unknown tool, malformed request) from tool *execution* errors (`isError: true` in the result). Only the second kind reaches the model as recoverable information.
