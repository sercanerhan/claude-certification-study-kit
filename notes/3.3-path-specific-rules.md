title: Path-specific rules (paths frontmatter)
---
## Core idea
A file in `.claude/rules/` can carry YAML frontmatter with a `paths` list of glob patterns. The rule then loads **only when Claude works on a matching file**. Conventions apply by file type wherever the files live, and unrelated rules stay out of context, which saves tokens and reduces noise.

## What the exam tests
- Syntax: frontmatter `paths: ["terraform/**/*"]` or `paths: ["**/*.test.tsx"]`. A rule with no `paths` loads always.
- Conditional loading cuts irrelevant context and token use.
- Glob rules beat directory-level CLAUDE.md when the files are **spread across the codebase**: tests next to components, migrations in every service, `*.repository.ts` in many packages.
- Directory CLAUDE.md files are bound to one directory tree. They can't express "all test files everywhere".

## Exam traps
- **Trap:** one root CLAUDE.md with headed sections, trusting Claude to infer which applies → **Instead:** explicit glob matching is deterministic.
- **Trap:** a CLAUDE.md copied into every folder that contains tests → **Instead:** one rule with `**/*.test.tsx`.
- **Trap:** skills for conventions → **Instead:** skills need invocation or Claude choosing to load them. Rules attach automatically based on the file path.
- **Trap:** a rule file without frontmatter for niche Terraform conventions → **Instead:** without `paths` it loads in **every** session. Add `paths`.

## Example
```markdown
---
paths:
  - "**/*.test.tsx"
  - "**/*.test.ts"
---
- Use describe/it; one behaviour per test.
- Build data with factories from test/factories, never inline literals.
```

## Remember
- `paths` + globs = load only for matching files.
- No `paths` = always loaded.
- Files spread across directories → glob rule. A single self-contained directory → subdirectory CLAUDE.md is fine.
- `**/*.ext` matches at any depth.
- Docs note: current docs say a path-scoped rule loads when Claude reads, writes or edits a matching file (including `cat`/`head` via Bash). `paths` accepts a YAML list or a comma-separated string, and supports brace expansion such as `src/**/*.{ts,tsx}`.
