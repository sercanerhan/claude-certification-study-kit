title: Error propagation in multi-agent systems

## Core idea
In a coordinator-subagent system, failures should be handled at the lowest level that can fix them, and the rest should be reported upward **with enough context to act on**. A subagent retries transient failures itself. Anything it can't resolve goes to the coordinator as a structured report: what failed, what was attempted, partial results and possible alternatives. Both extremes are wrong: hiding failures as success, and killing the whole workflow over one error.

## What the exam tests
- Structured error context includes the failure type, attempted query, partial results and alternative approaches.
- An **access failure** (timeout, needs a retry decision) is not a **valid empty result** (the query succeeded with 0 matches).
- Generic statuses ("search unavailable") hide context the coordinator needs.
- Anti-patterns: silent suppression (empty result marked as success) and terminating the whole workflow on one failure.
- Local recovery for transient failures. Propagate only what is unresolved, with partial results.
- The synthesis output carries **coverage annotations**: which findings are well supported and which areas have gaps because sources were unavailable.

## Exam traps
- **Trap:** retry with backoff, then return "search unavailable" → **Instead:** retry locally, then return structured details.
- **Trap:** catch the timeout and return `[]` as success → **Instead:** the coordinator would conclude that nothing exists.
- **Trap:** treat "0 results" as a failure → **Instead:** it is a valid finding. Don't retry it.
- **Trap:** any subagent exception aborts the research run → **Instead:** let the coordinator decide whether to retry, use an alternative or continue with partial results.
- **Trap:** synthesis silently drops the sources that failed → **Instead:** annotate the gaps in the report.
- **Trap:** a dedicated error-handler agent with a shared queue → **Instead:** subagents recover locally and the coordinator decides.

## Example
```json
{"status": "partial",
 "failure": {"type": "timeout", "source": "patent_db", "attempted": "solid-state battery patents 2022-2025",
             "retriesDone": 2, "alternatives": ["use EPO mirror", "narrow date range"]},
 "results": {"academic": 15, "industry_reports": 0},
 "notes": "industry_reports query succeeded with 0 matches"}
```
Report section: "Patent landscape: **coverage gap** (source unavailable); findings below rely on academic sources only."

## Remember
- Recover locally, propagate the rest with context.
- Timeout ≠ empty result.
- Never mark a failure as success, and never let one failure kill the run.
- Coverage annotations make the gaps visible to readers.
